# Write Connection — composition tutoring

Personalised tutoring pages built from marked composition drafts.

## Folder convention

```
term-<n>/week-<nn>-<yyyy-mm-dd>/
    <composition-name>.html     tutoring page, self-contained
    scans/                      the marked draft, upright
    README.md                   what was marked, and what to do next
```

`term` and `week` come from the header of the worksheet; the date is the
one written in its **DATE** field, in ISO order so the folders sort
chronologically within a term.

⚠ Week 10's DATE field was blank and its folder date was chosen by hand.
Week 11 is dated 7 September, which falls *before* it, so Week 10 was most
likely around **31 August 2026**. The folder can be renamed once the real
date is known.

## Consistency

`.claude/skills/mark-composition/` holds the house style, so every week's page
comes out the same. Any Claude session opened in this repository picks it up
automatically — drop in the photos and say "this week's composition".

| File | What it holds |
| --- | --- |
| `SKILL.md` | The workflow: how to file, transcribe, catalogue marks, and what goes on the page |
| `references/marking-codes.md` | What each red code means and how to teach it. Append new codes as they appear |
| `references/page-spec.md` | Palette, type, layout and section order — the visual identity, fixed |
